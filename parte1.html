Bienvenido al mundo de las matemáticas

Explora conceptos matemáticos mediante fórmulas, ejemplos y gráficos interactivos.

Las matemáticas nos permiten describir y comprender muchos fenómenos de nuestro mundo.

Álgebra

Una ecuación de segundo grado tiene la forma:

\[ ax^2 + bx + c = 0 \]

Sus soluciones pueden calcularse mediante la fórmula:

\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

Geometría

Área de un círculo

El área de un círculo se calcula mediante:

\[ A = \pi r^2 \]

donde \(r\) representa el radio.

Teorema de Pitágoras

Para un triángulo rectángulo:

\[ a^2 + b^2 = c^2 \]

Cálculo

La derivada de una función permite estudiar cómo cambia una cantidad respecto de otra.

\[ \frac{d}{dx}(x^n) = nx^{n-1} \]

Por ejemplo:

\[ \frac{d}{dx}(x^3) = 3x^2 \]
